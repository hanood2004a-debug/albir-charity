## 📌 عن المشروع (About The Project)
**موقع جمعية البر** هو منصة رقمية إنسانية وخيرية، تهدف إلى تسهيل الوصول للمبادرات المجتمعية وعرض الحملات الإغاثية. 
تم تصميم المنصة لتكون حلقة وصل موثوقة بين المتبرعين والمحتاجين، مع التركيز على تجربة مستخدم (UX) بسيطة ومريحة تشجع على التبرع وتبرز شفافية وأثر المشاريع الخيرية.

## ✨ المميزات (Features)
- 🌍 **عرض تفاعلي للحملات:** تصميم يبرز المشاريع الإغاثية والخيرية بطريقة تشد انتباه الزوار.
- 📱 **واجهة متجاوبة (Responsive):** تصفح ممتاز ومريح عبر أجهزة الجوال والشاشات المختلفة.
- ♿ **إمكانية الوصول (Accessibility):** تصميم يراعي سهولة القراءة والتصفح لكافة فئات المجتمع.
- 🚀 **أداء سريع ومستقر:** كود نظيف يضمن سرعة تحميل الموقع وتصفح المشاريع بدون تعليق.
